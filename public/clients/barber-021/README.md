## Reguli

- **JPG mai bun decât PNG** pentru fotografie / ilustrație raster (mărime mai mică)
- **Quality 85** la export
- **Fără spații** în nume — folosește cratimă: `hero-razor-A.jpg` ✓ / `Hero Razor A.jpg` ✗
- Diacriticele OK în conținut, dar NU în nume de fișier
- Cere-mi să fac AVIF/WebP optimization după ce le pui — fac asta într-un pas separat când avem totul
